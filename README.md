# Spotify Music Player

A responsive Spotify-inspired music player built with HTML, CSS and JavaScript. This is a learning project and is not affiliated with Spotify.

<!-- Add a screenshot or GIF of the player here, for example:

## Features

- Play / Pause the current song
- Next / Previous track controls
- Select any song directly from the playlist
- Live progress bar that follows the song
- Responsive layout for mobile, tablet and desktop

## Tech Stack

| Area | Technology |
| --- | --- |
| Structure | HTML5 |
| Styling | CSS3 |
| Logic | JavaScript (DOM manipulation and the HTML audio API) |

## What I Learned

- Controlling audio with JavaScript (play, pause, track switching)
- Updating the UI dynamically with DOM manipulation
- Building an interactive progress bar
- Designing a responsive, app-style layout

## Run Locally

1. Clone the repository:
   ```bash
   git clone https://github.com/asheeshkumar7521-lab/spotify.git
   ```
2. Open the folder:
   ```bash
   cd spotify
   ```
3. Open `index.html` in your browser (or use the VS Code Live Server extension).
